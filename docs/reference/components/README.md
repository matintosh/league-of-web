# Component reference images

Generated by `scripts/annotate_refs.py` from a spec in `docs/reference/specs/`.

For each component box in a spec, two artifacts are produced:
- **`<ref>__<slug>.png`** — a CROP of just that component (build/verify target).
- **`<ref>__annotated.png`** — the MAIN ref with a labeled RED RECTANGLE per component (shows where each lives in context).

## Workflow (build + review loops)

1. A RESEARCH/REVIEW agent measures each component's bounding box in the ref
   (Playwright getBoundingClientRect on the live site, or by eye on the ref) and
   writes a spec: `docs/reference/specs/<ref>.json` with boxes
   (absolute `{x,y,w,h}` or normalized `{fx,fy,fw,fh}` fractions of the ref).
2. Run `python3 scripts/annotate_refs.py docs/reference/specs/<ref>.json`.
3. BUILDER brief links the component crop (`__<slug>.png`) as the isolated target
   AND the annotated ref (`__annotated.png`) for context.
4. REVIEW diff agent measures the built component vs the crop.

Regenerate any time: `python3 scripts/annotate_refs.py docs/reference/specs/*.json`
